# LifeOS

Android-приложение-помощник: календарь и задачи, финансы, покупки, привычки, заметки,
утренний обзор и голосовой ИИ-помощник с анимированным роботом.

Стек: Kotlin, Jetpack Compose, Room, DataStore, Firebase (регистрация и облачное сохранение).
Оформление: дизайн-система проекта (тёмный фон, оранжевый акцент, скруглённые «таблетки»).
Акцент можно сменить на зелёный (цвет робота) в «Профиль → Оформление».

> **Статус: версия 0.1, код ещё ни разу не собирался и не запускался на телефоне.**
> Он написан в среде без доступа к Android SDK, поэтому первая сборка в Android Studio наверняка
> покажет мелкие ошибки компиляции. Их нужно поправить до первого запуска. Это нормально для такого объёма
> нового кода, но знайте об этом заранее.

## Как собрать

1. Установите [Android Studio](https://developer.android.com/studio) (свежую стабильную версию).
2. Откройте папку проекта (`File → Open`), дождитесь синхронизации Gradle.
3. Подключите телефон с Android 8.0+ (включите «Отладку по USB») или создайте эмулятор.
   Для проверки голоса лучше настоящий телефон.
4. Нажмите **Run**.

### Подключение облака (регистрация с сохранением данных)

Без этого шага приложение работает в локальном режиме: аккаунт и данные лежат только на телефоне.

1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com) (тариф Spark бесплатный, Analytics можно выключить).
2. Добавьте Android-приложение с именем пакета `com.lifeos.app` и скачайте `google-services.json`.
3. Включите **Build → Authentication → Sign-in method → Email/Password** и создайте базу **Build → Firestore Database**.
4. Подключите файл к сборке одним из способов (в Git сам файл не попадает, он в `.gitignore`):
   - **сборка на GitHub (как у нас):** репозиторий → Settings → Secrets and variables → Actions → New repository secret, имя
     `GOOGLE_SERVICES_JSON`, значение: весь текст файла. Дальше каждая сборка на GitHub будет с облаком;
   - **Android Studio:** положите файл в папку `app/`.
5. В Firestore задайте правила, чтобы каждый видел только свои данные:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

После входа данные (в том числе то, что помощник запомнил о вас) сохраняются в облаке автоматически через несколько секунд
после любого изменения, а при входе на другом телефоне подтягиваются обратно.

**ИИ по аккаунту.** Когда облако подключено, а сервер ИИ (`server/ai-relay`) знает ваш проект Firebase, помощник с ИИ
доступен всем, кто зарегистрировался или вошёл в приложение, и ничего вставлять не нужно. Сервер проверяет подпись входа
Google, поэтому посторонние без аккаунта ИИ не получают, а лимит считается на каждый аккаунт. Для этого в воркере задаётся
переменная `FIREBASE_PROJECT_ID` (значение `project_id` из `google-services.json`).

| Безопасность | PIN-код, отпечаток/лицо, запрет скриншотов, скрытие уведомлений на экране блокировки |
| Оформление | Цвет, свечение, живые обои |
| Профиль | Аккаунт, уведомления, конфиденциальность |
| Утренний обзор | Погода, события, задачи, расходы, привычки, цель. Приходит уведомлением и красивым окном на экране блокировки, когда утром включаете телефон |

| Магазин роботов | Бесплатные, платные и лимитированные роботы, каталог в `SkinCatalog.kt` |

## Голосовой помощник

Помощник **не показывается**, пока его не позвали. Включите «Слушать «LifeOS» в фоне»
(Профиль → Настройки помощника). Тогда он отзывается на «LifeOS …», «OS …» и на имя, которое вы ему дали.

- Робот появляется поверх экрана, ходит, и если встаёт на кнопку или поле ввода, уходит в сторону.
  Для этого нужны разрешения «Поверх других приложений» и (необязательно) сервис «робот видит экран».
  Сервис передаёт роботу только границы кнопок и полей, тексты не читаются.
- Команды выполняются по-настоящему: будильник и таймер ставятся в приложении «Часы», заметки, задачи,
  покупки и расходы попадают в базу. Пример: «LifeOS, поставь будильник на 7:30».
- Три голоса: женский, мужской и свой (тон, скорость, выбор голоса синтезатора).
- **ИИ внутри помощника.** Для пользователей ключ не нужен: приложение обращается к бесплатному серверу-посреднику
  (`server/ai-relay`, настройка один раз на 10 минут, см. `server/ai-relay/README.md`), который держит ключ провайдера у себя.
  Общий бесплатный лимит один на всех пользователей: примерно несколько десятков вопросов к ИИ в сутки, потом нужен платный ключ
  на сервере (приложение обновлять не придётся); простые команды ИИ не тратят. Можно вставить и свой ключ Anthropic API. Помощник отвечает на любые вопросы, решает задачи (математика,
  тексты, советы) и сам выбирает действие: ставит будильник и таймер, создаёт напоминание, заметку, покупку, расход,
  ищет в интернете, звонит, читает и нажимает по экрану. Это не просто чат: ИИ получает «инструменты» приложения
  (`AiAgent.kt`) и вызывает их. Если ИИ не подключён или лимит кончился, работают готовые команды и счёт.
- **ИИ в телефоне (запасной режим).** В настройках помощника можно скачать маленькую модель (Qwen 2.5 1.5B, Apache 2.0, около
  1,6 ГБ, запускается через LiteRT-LM от Google). Она работает без интернета и без лимитов, включается сама, когда облачный ИИ
  недоступен или лимит кончился, или всегда, если включить переключатель. Честные ограничения: заметно слабее облачного ИИ, русский
  и точность скромнее, действий на телефоне не выполняет (их делают команды), нужно около 2 ГБ места и 6 ГБ памяти, греет телефон,
  отвечает медленно. Модель один раз зеркалится из Hugging Face на GitHub Releases (`llm-model-qwen`) сборкой.
- **Платный ключ как запас.** В сервере ИИ можно добавить платный ключ Claude, который включается только когда бесплатный лимит
  кончился (с потолком запросов в сутки и лимитом расходов у провайдера), см. `server/ai-relay/README.md`.
- **Память.** «Запомни, что у меня аллергия на орехи»: помощник кладёт это в память и учитывает в разговорах. Список
  памяти виден в настройках помощника, любой пункт можно забыть. Так он подстраивается под вас со временем.
- **Счёт без ИИ:** «сколько будет 15 умножить на 23», «посчитай 18 процентов от 4500», «корень из 144», «2 в степени 10».
- **Напоминания:** «напомни в 15:00 позвонить маме», «напомни завтра в 15:00 купить билеты», «напомни в пятницу в 18:30
  про встречу», «напомни 20 числа оплатить интернет». Если не сказали время или что напомнить, помощник переспросит.
  Напоминание срабатывает уведомлением со звуком в нужную минуту (точный будильник, `ReminderScheduler`).
- **Заметка с блокнотом.** Скажите «заметка»: на экране появляется листок с роботом, слова вписываются по мере речи, слово
  «остановить» (или кнопка «Сохранить») завершает запись, заметка сохраняется. Для листка нужно «Поверх других приложений»,
  без него запись идёт так же, но без листка.
- **Видеть экран и управлять им.** «Что на экране», «нажми отправить», «прокрути вниз». Это работает **только** через
  специальный доступ Android (служба специальных возможностей). Без этого доступа смотреть на экран и нажимать за
  пользователя не может ни одно приложение, это защита системы. Включается один раз в настройках помощника
  («Открыть» → LifeOS → переключатель). На Android 13+ для установленного вручную APK сначала нужно в сведениях о приложении
  нажать ⋮ → «Разрешить ограниченные настройки». Пароли и поля ввода паролей не читаются. Передвигаться по экрану робот
  может и без этого доступа: ему хватает «Поверх других приложений».
- Заметка голосом мгновенно (приложение открывать не нужно): кнопка с блокнотом на главной, виджет-микрофон,
  плитка в шторке (работает на экране блокировки), долгое нажатие на иконку LifeOS, кнопка «Заметка» в уведомлении
  или голос «LifeOS, запиши …». Фраза сама определяет тип: «купить молоко» в покупки, «завтра в 10 позвонить врачу»
  в календарь, «потратил 300 на кофе» в финансы, остальное в заметки.
- Команды телефона: «открой Телеграм», «позвони маме», «напиши Ивану …», «включи фонарик», «громче/тише»,
  «следующий трек/пауза», «проложи маршрут до …», «найди в интернете …», «сфотографируй», «открой настройки Wi-Fi»,
  «назад/домой/последние/шторка/заблокируй экран» (нужен сервис «робот видит экран»), «который час», «сколько заряда».

### Магазин роботов

Каталог лежит в `app/src/main/java/com/lifeos/app/data/SkinCatalog.kt`. Чтобы добавить нового робота (платного
или лимитированного), добавьте строку в список `SkinCatalog.all`. **Оплата пока заглушка**: платные роботы
выдаются бесплатно (`DemoPurchaseGateway`). Для реальных платежей нужна Google Play Billing, а подарки в стиле
Telegram потребуют своего сервера.

## Известные ограничения

- Утренний обзор на экране блокировки появляется, когда включён экран, приложение живо в памяти и выдано
  «Поверх других приложений». Если система выгрузила LifeOS, останется обычное уведомление.
- Слушание: основной движок офлайн (Vosk, русская модель около 45 МБ, скачивается один раз, по безлимитному Wi‑Fi сама
  или кнопкой в «Проверке помощника»). Без модели используется голосовой ввод Google (нужны приложение «Google» и интернет).
  Заметки по умолчанию тоже пишутся офлайн-моделью; если она ошибается в словах, включите «Точная диктовка через Google».
- Самый надёжный вызов не голосом: сделайте LifeOS помощником по умолчанию (Проверка помощника → «Выбрать помощником»),
  тогда удержание кнопки питания зовёт робота. Работает не на всех оболочках телефонов.
- После перезагрузки телефона Android не даёт включить микрофон сам: придёт уведомление, достаточно одного нажатия.
- Помощник держит процессор бодрствующим, чтобы слышать с выключенным экраном, поэтому заряд расходуется заметнее.
- Помощник уходит, если вы молчите, и вызывается заново словом «LifeOS» или «ОС».
- **Выключенный телефон** (полностью, без питания) ничего слышать не может. Голос работает с выключенным
  экраном и заблокированным телефоном.
- Android не разрешает запускать микрофонный сервис в фоне после перезагрузки. Прослушивание «LifeOS» возвращается,
  когда вы открываете приложение. Отключите для LifeOS экономию заряда, иначе система может остановить сервис.
- Постоянное прослушивание через системное распознавание речи расходует заряд и на некоторых телефонах пищит
  при каждом перезапуске. Для «настоящего» офлайн-слова активации лучше подключить Porcupine или аналог.
- Будильник из фона ставится, если выдано разрешение «Поверх других приложений».
- Android запрещает приложениям самим включать Wi-Fi, Bluetooth, режим полёта и отправлять SMS без нажатия.
  Робот в таких случаях открывает нужный экран настроек или окно сообщения.
- Робот нарисован кодом (2.5D). Настоящая 3D-модель с анимацией потребует отдельной графики.
- Записи звука не попадают в облако, только названия. При переносе на другой телефон их не будет.
- Автоучёт читает уведомления банков, а не сами банковские приложения (у банков нет открытого доступа к картам).
  Нужно один раз разрешить доступ к уведомлениям. Только рубли. Формулировки банков разные, поэтому часть
  операций может не распознаться или попасть не в ту категорию. Операции другими валютами пропускаются.
- PIN-код блокирует приложение, если вы отсутствовали дольше 10 секунд. Забытый PIN сбрасывается выходом из аккаунта.
- Живые обои простые (светящиеся шары в цвете акцента), без робота.
- Ключ ИИ хранится на телефоне. Для публичного релиза его нужно убрать на свой сервер. API Anthropic платный и оплачивается
  отдельно от подписки Claude (по числу запросов, на обычное использование хватает нескольких долларов).
- ИИ ошибается, как и любой ИИ: важные расчёты и действия стоит перепроверять. Помощник «развивается» через память
  (запоминает факты о вас) и через обновления приложения, сама модель на телефоне не переобучается.
- Управление экраном зависит от самих приложений: у некоторых (банки, защищённые окна) Android скрывает содержимое экрана, и
  читать или нажимать там нельзя.
- Распознавание речи офлайн иногда ошибается в редких словах. Для заметок есть переключатель «Точная диктовка через Google».
- Автотесты парсера команд (даты, время, числа словами, счёт) прогнаны, но на настоящем телефоне это нужно проверять руками.

## Чек-лист: что подключить и что сделать

1. **Собрать приложение.** Установите Android Studio (Ladybug или новее), откройте папку проекта, дождитесь
   синхронизации Gradle, подключите телефон по USB (включите «Отладка по USB») и нажмите Run. Если появятся
   красные ошибки, пришлите текст, я исправлю.
2. **Подключить Firebase (облако и регистрация).** Раздел «Подключение облака» выше: создать проект, добавить
   Android-приложение `com.lifeos.app`, включить Email/Password и Firestore, положить `google-services.json`
   в `app/`, вставить правила безопасности. Без этого всё работает, но данные только на телефоне.
3. **Выдать разрешения на телефоне.** Доступ к уведомлениям (Финансы → «Разрешить доступ», для автоучёта), микрофон, уведомления, «Поверх других приложений», «Контакты и звонки»
   (Профиль → Настройки помощника), «Помощник видит экран и управляет им» (нужно только для команд «нажми …» и «что на экране»), точные будильники для напоминаний и утреннего обзора.
4. **Отключить экономию заряда для LifeOS** в настройках Android, иначе система остановит прослушивание.
5. **Добавить быстрые способы записи.** Плитка «Голосовая заметка» в шторку, виджет-микрофон на рабочий стол
   (Профиль → Виджеты).
6. **Подключить бесплатный ИИ для всех** (один раз): сервер-посредник по инструкции `server/ai-relay/README.md`
   (бесплатные Cloudflare и Groq, 10 минут), потом прислать мне адрес сервера, и он вшивается в сборку. Либо вставить свой ключ
   Anthropic API (console.anthropic.com → Billing → API Keys) в Профиль → Настройки помощника. Без ИИ помощник не отвечает на
   свободные вопросы и не понимает сложных просьб своими словами.
7. **Платежи в магазине роботов.** Сейчас заглушка. Нужны аккаунт разработчика Google Play, Google Play Billing
   и для подарков в стиле Telegram свой сервер. Новых роботов добавлять в `SkinCatalog.kt`.
8. **Настоящий 3D-робот.** Если нужна модель как на фото, потребуется 3D-художник или готовая анимация
   (Lottie/Rive/glTF), которую я подключу вместо рисунка кодом.
9. **Релиз.** Подписать приложение своим ключом, перенести ключ ИИ на свой сервер, добавить политику
   конфиденциальности (приложение слушает микрофон и использует специальные возможности), пройти проверку Google Play.
