# LifeOS

Android-приложение-помощник: календарь и задачи, финансы, документы, покупки, привычки, заметки,
утренний обзор и голосовой ИИ-помощник с анимированным роботом.

Стек: Kotlin, Jetpack Compose, Room, DataStore, Firebase (регистрация и облачное сохранение).
Оформление: дизайн-система проекта (тёмный фон, оранжевый акцент, скруглённые «таблетки»).
Акцент можно сменить на зелёный (цвет робота) в «Профиль → Оформление».

> **Статус: версия 0.1, код ещё ни разу не собирался и не запускался на телефоне.**
> Он написан в среде без доступа к Android SDK, поэтому первая сборка в Android Studio наверняка
> покажет мелкие ошибки компиляции. Их нужно поправить до первого запуска. Это нормально для такого объёма
> нового кода, но знайте об этом заранее.

## Как собрать

1. Установите [Android Studio](https://developer.android.com/studio) (свежую стабильную версию).
2. Откройте папку проекта (`File → Open`), дождитесь синхронизации Gradle.
3. Подключите телефон с Android 8.0+ (включите «Отладку по USB») или создайте эмулятор.
   Для проверки голоса лучше настоящий телефон.
4. Нажмите **Run**.

### Подключение облака (регистрация с сохранением данных)

Без этого шага приложение работает в локальном режиме: аккаунт и данные лежат только на телефоне.

1. Создайте проект на [console.firebase.google.com](https://console.firebase.google.com).
2. Добавьте Android-приложение с именем пакета `com.lifeos.app`.
3. Включите **Authentication → Email/Password** и создайте базу **Firestore**.
4. Скачайте `google-services.json` и положите в папку `app/`. Файл в Git не попадает (он в `.gitignore`).
5. В Firestore задайте правила, чтобы каждый видел только свои данные:

```
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == uid;
    }
  }
}
```

После входа данные сохраняются в облаке автоматически через несколько секунд после любого изменения,
а при входе на другом телефоне подтягиваются обратно.

## Что внутри

| Раздел | Что делает |
|---|---|
| Регистрация / вход | Email и пароль, карточка в стиле дизайн-системы |
| Главная | Сводка дня, быстрые разделы, цель месяца, кнопка вызова помощника |
| Календарь | События и задачи по дням, неделя, фильтры |
| Финансы | Расходы по категориям за месяц, история |
| Документы | Список документов по категориям (пока только названия) |
| Покупки, Привычки, Заметки | Списки, прогресс привычек, текстовые и голосовые заметки |
| Утренний обзор | Погода, события, задачи, расходы, привычки, цель. Что показывать и во сколько, выбирает пользователь |
| ИИ-помощник | Чат, настройки имени и голоса, разрешения |
| Магазин роботов | Бесплатные, платные и лимитированные роботы, каталог в `SkinCatalog.kt` |

## Голосовой помощник

Помощник **не показывается**, пока его не позвали. Включите «Слушать «LifeOS» в фоне»
(Профиль → Настройки помощника). Тогда он отзывается на «LifeOS …», «OS …» и на имя, которое вы ему дали.

- Робот появляется поверх экрана, ходит, и если встаёт на кнопку или поле ввода, уходит в сторону.
  Для этого нужны разрешения «Поверх других приложений» и (необязательно) сервис «робот видит экран».
  Сервис передаёт роботу только границы кнопок и полей, тексты не читаются.
- Команды выполняются по-настоящему: будильник и таймер ставятся в приложении «Часы», заметки, задачи,
  покупки и расходы попадают в базу. Пример: «LifeOS, поставь будильник на 7:30».
- Три голоса: женский, мужской и свой (тон, скорость, выбор голоса синтезатора).
- Для свободного разговора вставьте ключ Anthropic API в настройках помощника. Без ключа работают команды.
- Заметка при выключенном экране: добавьте плитку «Голосовая заметка» в шторку (работает и на экране блокировки)
  или говорите «LifeOS, запиши …» при включённом прослушивании.

### Магазин роботов

Каталог лежит в `app/src/main/java/com/lifeos/app/data/SkinCatalog.kt`. Чтобы добавить нового робота (платного
или лимитированного), добавьте строку в список `SkinCatalog.all`. **Оплата пока заглушка**: платные роботы
выдаются бесплатно (`DemoPurchaseGateway`). Для реальных платежей нужна Google Play Billing, а подарки в стиле
Telegram потребуют своего сервера.

## Известные ограничения

- **Выключенный телефон** (полностью, без питания) ничего слышать не может. Заметки голосом работают с выключенным
  экраном и заблокированным телефоном.
- Android не разрешает запускать микрофонный сервис в фоне после перезагрузки. Прослушивание «LifeOS» возвращается,
  когда вы открываете приложение. Отключите для LifeOS экономию заряда, иначе система может остановить сервис.
- Постоянное прослушивание через системное распознавание речи расходует заряд и на некоторых телефонах пищит
  при каждом перезапуске. Для «настоящего» офлайн-слова активации лучше подключить Porcupine или аналог.
- Будильник из фона ставится, если выдано разрешение «Поверх других приложений».
- Робот нарисован кодом (2.5D). Настоящая 3D-модель с анимацией потребует отдельной графики.
- Документы пока хранят только записи, без файлов и шифрования.
- Не сделано из третьего макета: виджеты рабочего стола, блокировка приложения по PIN/отпечатку,
  живые обои, экран «Приложения» как отдельная сетка с настройками.
- Ключ ИИ хранится на телефоне. Для публичного релиза его нужно убрать на свой сервер.
