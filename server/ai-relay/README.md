# Бесплатный ИИ для всех пользователей LifeOS

Приложение само не хранит ключ ИИ: APK публичный, любой ключ из него вытащат и потратят. Поэтому между приложением и ИИ стоит
маленький сервер-посредник (`worker.js`, около 150 строк). Ключ лежит на нём в секрете, у пользователей ничего настраивать не нужно.

Всё бесплатно: Cloudflare Workers (до 100 000 запросов в день) + бесплатный тариф Groq. **Важно про лимиты:** у бесплатного
тарифа ИИ лимит один на весь сервис, а не на каждого пользователя. По странице лимитов Groq (на момент проверки) для модели
`openai/gpt-oss-120b` это около 1000 запросов и 200 тысяч токенов в сутки на организацию; точные цифры показаны в вашем аккаунте
(console.groq.com → Settings → Limits). Один запрос помощника весит 2–3 тысячи токенов (описание инструментов и подсказка), а вопрос
с действием это 2 запроса. Поэтому на всех пользователей хватит примерно на **несколько десятков вопросов в сутки**: для вас и пары
друзей достаточно, для сотен пользователей нет. Простые команды (будильник, таймер, заметка, напоминание, счёт, расход,
покупки, звонок) разбираются на самом телефоне и ИИ не тратят. Когда лимит кончится, помощник честно скажет об этом, а эти команды
продолжат работать. Когда пользователей станет больше, подключите платный ключ (см. ниже), приложение обновлять не придётся.

## Настройка (один раз, 10 минут)

1. **Ключ провайдера.** Зарегистрируйтесь на console.groq.com (бесплатно), раздел API Keys → Create API Key, скопируйте ключ (`gsk_…`).
2. **Сервер.** Зарегистрируйтесь на dash.cloudflare.com (бесплатно) → Workers & Pages → Create → Create Worker → имя `lifeos-ai` → Deploy →
   Edit code → удалите всё, вставьте содержимое файла `worker.js` из этой папки → Deploy.
3. **Секрет.** В воркере: Settings → Variables and Secrets → Add → тип **Secret**, имя `UPSTREAM_KEY`, значение ключ из шага 1 → Deploy.
4. **Проверка.** Откройте адрес воркера в браузере (`https://lifeos-ai.<ваше-имя>.workers.dev`). Должно быть написано «LifeOS AI relay работает. Ключ провайдера: задан».
5. **Подключение к приложению.** Любой из способов:
   - пришлите адрес мне, я вшью его в сборку, и все пользователи получат ИИ из коробки;
   - или на GitHub: репозиторий → Settings → Secrets and variables → Actions → Variables → New variable `AI_RELAY_URL` и перезапустите сборку;
   - или сразу на своём телефоне: Профиль → Настройки помощника → ИИ → «Дополнительно: адрес сервера ИИ».

## ИИ только для вошедших в аккаунт (рекомендуется)

Когда в приложении подключено облако (Firebase, см. главный README), добавьте в воркер переменную `FIREBASE_PROJECT_ID`
со значением `project_id` из файла `google-services.json`. Тогда:
- ИИ работает у каждого, кто зарегистрировался или вошёл в приложение, ничего вводить не нужно, а на новом телефоне после входа всё то же самое;
- без входа сервер отвечает отказом, поэтому адрес воркера из APK бесполезен посторонним;
- сервер проверяет подпись входа Google и считает лимит на каждый аккаунт (`USER_DAILY_LIMIT`, по умолчанию 25 запросов в сутки).

Чтобы счётчики не сбрасывались при перезапуске воркера, создайте хранилище: Cloudflare → Storage & Databases → KV → Create → имя `limits`,
затем в воркере Settings → Bindings → Add → KV namespace, переменная `LIMITS`. Без него счёт ведётся в памяти и он мягкий.

## Необязательные настройки (Variables в воркере)

| Имя | Что делает | По умолчанию |
|---|---|---|
| `MODEL` | модель провайдера | `openai/gpt-oss-120b` |
| `UPSTREAM_URL` | адрес чата провайдера (OpenRouter, Gemini и другие, совместимые с OpenAI) | Groq |
| `UPSTREAM_KIND` | `openai` или `anthropic` (платный ключ Claude: тогда `MODEL` например `claude-sonnet-5-5`) | `openai` |
| `HOURLY_LIMIT` | запросов в час с одного устройства или аккаунта | 40 |
| `FIREBASE_PROJECT_ID` | требовать вход в аккаунт и считать лимит на аккаунт | выключено |
| `USER_DAILY_LIMIT` | запросов в сутки на аккаунт (при `FIREBASE_PROJECT_ID`) | 25 |
| `APP_TOKEN` | общий пароль приложения (вместе с `AI_RELAY_TOKEN` при сборке) | нет |

## Честно о защите и приватности

- Лимит на устройство и пароль приложения это **мягкая** защита: APK публичный, и его адрес можно достать. Главный предохранитель в том, что
  бесплатный тариф не может «сжечь деньги»: самое плохое, что случится, это исчерпанный дневной лимит. Если подключите платный ключ,
  обязательно поставьте у провайдера месячный лимит расходов.
- Вход в аккаунт (`FIREBASE_PROJECT_ID`) защищает намного лучше пароля приложения, но зарегистрировать много аккаунтов скриптом можно:
  регистрация по email бесплатна. Общий бесплатный лимит провайдера всё равно остаётся потолком. Следующий шаг защиты
  Firebase App Check (подтверждение, что запрос идёт из настоящего приложения), когда пользователей станет много.
- Фразы пользователей, имя и запомненные факты проходят через ваш воркер и сервис ИИ. У некоторых бесплатных тарифов (например,
  у Google Gemini) данные могут использоваться для улучшения моделей, поэтому по умолчанию выбран Groq. Проверьте условия провайдера и
  укажите это в политике конфиденциальности перед публичным релизом.
- Воркер ничего не сохраняет: лимиты считаются в памяти.

Проверка перевода форматов: `node test.mjs` (нужен Node 18+).
